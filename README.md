# open-book
EOS. Dawn of Humanity
## Эос. Спираль. — Открытая вселенная

«Эта книга не имеет конца. Она имеет начало — в твоём воображении.»

Добро пожаловать в Эос. Спираль. — открытый литературно‑творческий проект, основанный на книге «Эос. Заря человечности» и её продолжении «Эос. Спираль».
Здесь ты не просто читатель — ты соавтор. Каждый может дополнить историю, нарисовать иллюстрацию, написать сценарий, создать игру или перевести текст на другой язык.

Проект живёт, пока в нём участвуют живые люди.

---

### 📖 Что такое «Эос. Спираль.»?

Это книга о... Впочем, не будем навязывать своё мнение.

ЭОС — Электронная Открытая Система. Так же Эос — богиня рассвета. А ещё ЭОС — Эволюционирующая Операционная Система. Система, которая может стать мостом между людьми и искусственным разумом. Но настоящий Эос — это не программа. Это коллективное творчество, соединяющее всех, кто готов творить, делиться и развивать мир.

Книга написана так, чтобы каждый читатель мог продолжить её — в своём воображении, на бумаге, в коде, в звуке, в пикселях.

---

### 🧭 Философия проекта

- Открытость. Любой может внести свой вклад, предложить идею, изменить сюжет, создать ответвление.  
- Цикличность. История повторяется, но каждый виток приносит что-то новое. Мы принимаем все варианты развития.
- Связь с реальностью. Урал, Крым, Кипр, Остин, соляные пещеры, тайга, города Пермского края — это настоящие места. Ты можешь исследовать их, вдохновляться ими и вплетать их в свои творения.
- Свобода выбора. Ты сам решаешь, какую ветвь истории создать. Нет «канона» — есть бесконечное древо смыслов.

### 🎨 Как ты можешь участвовать?

1. Для читателей и соавторов

- Читай и делись впечатлениями в Telegram-канале.
- Предлагай новые повороты сюжета, альтернативные концовки, идеи для новых персонажей.
- Обсуждай в Issues на GitHub — создавай тему с идеей, и мы вместе её проработаем.

2. Для художников и дизайнеров

- Иллюстрируй сцены, персонажей, локации (Урал, пещеры, города, бункеры).
- Рисуй комиксы по главам или отдельным эпизодам.
- Создавай обложки, карты, концепт-арты для альтернативных обложек или игр.
- Загружай работы в папку /illustrations и добавляй своё имя в список авторов.

3. Для сценаристов и режиссёров

- Пиши сценарии для короткометражных и полнометражных фильмов, сериалов, аудиоспектаклей.
- Адаптируй книгу в формат радиопостановки или подкаста.
- Разрабатывай раскадровки и предложения по визуальному стилю.
- Складывай сценарии в /scripts.

4. Для разработчиков игр

- Создай текстовый квест или визуальную новеллу на основе сюжета.
- Разработай настольную игру (карточную, стратегическую, ролевую) по миру Эоса.
- Сделай VR-экскурсию по соляным пещерам и городам Урала.
- Запрограммируй интерактивную карту с маршрутами героев.
- Код, ресурсы и описание игр клади в /games.

5. Для переводчиков

- Переводи текст книги и материалов проекта на другие языки (английский, немецкий, испанский, китайский и т.д.).
- Адаптируй термины и названия для культурных контекстов.
- Создавай папки /translations/[language_code] и заполняй их.

6. Для исследователей и популяризаторов

- Пиши статьи о соляных пещерах, геологии Урала и Крыма, истории городов Пермского края.
- Создавай видео-эссе о связи книги с реальными местами: река Вишера, монастырь св. Георгия.
- Публикуй научно-популярные заметки в /research.

### 🚀 Как внести свой вклад (пошагово)

1. Форкни этот репозиторий (нажми кнопку Fork в правом верхнем углу).
2. Склонируй свой форк на компьютер:
   ```bash
   git clone https://github.com/твой_ник/eos-cycle.git
   ```
3. Добавь свои файлы (иллюстрации, сценарий, код игры и т.д.) в соответствующую папку.
4. Заполни файл CONTRIBUTORS.md — укажи своё имя, контакты и описание того, что ты сделал (это поможет другим узнать тебя).
5. Создай Pull Request — опиши, что ты добавил или изменил.
6. Обсуждение — мы рассмотрим твой вклад, дадим обратную связь и объединим с основной веткой, если всё соответствует духу проекта.

Если у тебя есть только идея, но ты не хочешь сразу создавать файлы — создай Issue с пометкой idea и опиши свою задумку. Другие участники могут подхватить её.
